# Hướng dẫn đóng góp

Chào mừng bạn đến với dự án! Chúng tôi rất vui khi bạn muốn đóng góp.

## Quy trình làm việc

### 1. Báo cáo lỗi
Nếu bạn tìm thấy một lỗi, vui lòng tạo một issue mới và sử dụng template "Báo cáo lỗi". Hãy cung cấp càng nhiều thông tin càng tốt.

### 2. Đề xuất tính năng
Nếu bạn có một ý tưởng hay, hãy tạo một issue mới và sử dụng template "Yêu cầu tính năng".

### 3. Tạo Pull Request
- Fork (phân nhánh) repository này.
- Tạo một nhánh mới từ nhánh `develop` (ví dụ: `git checkout -b feature/tinh-nang-moi`).
- Thực hiện thay đổi của bạn.
- Đảm bảo code của bạn tuân thủ các quy ước của dự án.
- Viết commit message theo quy ước [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/).
- Mở một Pull Request đến nhánh `develop` của repository gốc.

## Quy tắc chung

- **Code Style**: Đảm bảo code của bạn tuân thủ các quy tắc ESLint và Prettier đã được thiết lập.
- **Testing**: Viết và chạy các bài test cho những thay đổi của bạn.
- **Pull Request**: Cố gắng giữ PR nhỏ gọn, chỉ tập trung vào một tính năng hoặc một lỗi.
